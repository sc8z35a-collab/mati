# EVERCITY — LIVING CITY / UPDATE 02

## 目的・概要
ブラウザで遊べる一人称3D都市探索ゲームです。約648m四方、76棟の建物、5つの公園を備え、街路から建物の内部、各階、屋上まで探索できます。今回の拡張では交通信号・動く対象への衝突・実際の照明・住宅の内装と設備操作を追加しました。

Three.jsと手続き型の建築・家具モデルによるスタイライズされた架空都市です。写真測量・実在都市・写実的な外部モデルではありません。

## 完成した機能

### 都市と探索
- 9×9街区、76棟、5公園。約648m×648m。
- オフィス、カフェ、美術館、ホテル、マーケット、住宅。
- ビルの床スラブ、窓枠、庇、バルコニー、建物名サイン、屋上設備。
- 地上階は南側の入口から連続して歩いて入場。上階・屋上はエレベーターのフロア選択で移動。
- アトラス・タワーは25階建て。スカイラウンジと屋上あり。
- 街路樹、街灯、歩道、横断歩道、停止線、ベンチ、公園の水盤・彫刻、水辺。
- 9つの注目スポットへのファストトラベル。
- 探索率、現在地、方位、現在階、屋外ミニマップ、都市全体マップ。
- 室内ではミニマップが実際の壁・家具・扉・設備・現在位置を示すフロア図へ切り替わる。
- 初入場した建物を端末のlocalStorageに記録。

### 機能する信号と交通
- 内部の64交差点に、3Dの車両用信号と歩行者用信号。
- 80秒周期：南北青12秒→黄3秒→全赤3秒→東西青12秒→黄3秒→全赤3秒→歩行者青20秒→横断終了猶予22秒→全赤2秒。
- 交差点ごとに周期のオフセットあり。開始地点の交差点は固定オフセット。
- 信号の見た目・HUD・車両・歩行者が同じシミュレーション時計を参照。
- 40台の車が赤・黄信号で減速・停止し、青で加速して再発進。
- 前車との車間保持、交差方向の車両への譲り合い、プレイヤー・歩行者を避ける停止制御。
- ブレーキランプの点灯。夜間は近くの車のヘッドライトが路面を照らす。
- 95人の歩行者が横断前に待機し、歩行者青で横断開始。横断開始後は終了猶予中も渡り切る。
- 歩行者同士・車・プレイヤーへの衝突回避。障害物で通れない場合は待機後に折り返す。
- 最寄り交差点の南北・東西信号、歩行者状態、次の段階までの秒数を表示。
- 車・歩行者のシミュレーションは1/60秒の固定刻み。ダイアログ表示中は停止。

### 当たり判定
- プレイヤーと車・歩行者はすり抜けない。
- 車同士、車とプレイヤー、車と歩行者、歩行者同士の重なりを避ける。
- 建物壁、入口枠、エレベーターコア、主要家具、公園水盤、都市境界に衝突判定。
- 上階・屋上には移動範囲制限があり、転落しない。
- 開閉する住戸扉は回転角を考慮した衝突判定。開閉の軌道上にプレイヤーがいる場合は動作を拒否または停止。
- 小物すべてへの厳密な物理衝突、ラグドール、衝突ダメージはありません。

- 新しい注目住宅：メイプル・コート、カナル・ハウス、オーロラ・ハイツ。ヴェルダント・レジデンスも詳細内装へ更新。
- 地上ロビーにコンシェルジュカウンター、郵便受け、宅配荷物、ラウンジ家具、本棚。
- 共用廊下、部屋番号、玄関扉、靴箱、スリッパ、鏡、コート掛け。
- 住戸ごとにリビング・ダイニング・キッチン、主寝室、第二寝室兼書斎、浴室。
- 木目床、タイル、ラグ、ソファとクッション、ローテーブル、テレビ台、書棚。
- シンク、蛇口、IHコンロ、鍋、換気フード、上下収納、冷蔵庫、食器、調味料。
- ベッド、枕、ブランケット、ベッドサイド照明、ワードローブ、机、モニター、文具。
- 浴槽、水面、シャワーガラス、洗面台、鏡、トイレ、洗濯機、タオル、洗剤、ボトル類。

### 実際に操作できる住戸設備
設備に近づいて対象を向き、Eキーまたは「操作する」を押します。
- **玄関扉**：蝶番を軸にアニメーションで開閉。閉まった扉は通れない。
- **照明スイッチ**：住戸ごとの照明を点灯・消灯。照明器具の発光と実際の光源が連動。
- **テレビ**：都市番組→自然番組→電源OFFを切り替え。画面はブラウザで描いたオリジナルの番組グラフィック。外部動画・テレビ配信ではない。
- **キッチン水栓**：水を出す・止める。水流と波紋がアニメーションする。流体物理演算ではない。
- 操作対象が近いと照準が強調され、操作名が表示される。
- 設備の状態は同じページを開いている間、フロアを移動しても保持。再読み込み後は初期状態。

### ライティング
- 昼・ゴールデンアワー・夜を切り替え。
- 211か所の街灯器具。プレイヤー近傍の6灯に実際のスポットライトを割り当て、路面・歩道を照らす。
- 夜間の暖色の光だまり、光源周囲の柔らかいハロー、発光窓、信号灯。
- 室内は天井・ペンダントの位置に登録した照明器具を使用。カメラに追従する手持ちライト方式は廃止。
- 近くの室内照明6灯を使用し、うち2灯はシャドウ対応。住宅では滞在している住戸側の照明を優先。
- 室内の補助光、昼夜に応じた環境光、近くの車2台のヘッドライト。
- 太陽のシャドウ領域が現在の地区に追従。固定建築には簡略シャドウ形状を使用。
- シャドウは必要時に更新。レイトレーシング・全面的な動的GIではない。

## 操作
### スマホ
- 左スティック：前後左右への移動。
- ゲーム画面の右側をスワイプ：見回す。
- RUN：歩く／走るを切り替え。
- 「階を選ぶ」「操作する」：近くの設備を使用。
- マップを開き「内覧する」でモデル住戸へ直接移動。

### PC
- WASD／矢印：移動
- マウスドラッグ：視点
- ゲーム画面クリック：対応ブラウザではポインターロック
- Shift：走る
- Space：ジャンプ
- E：エレベーター・扉・設備を操作
- M：都市マップ
- Esc：ポインターロック解除／ダイアログを閉じる

扉の動作を拒否された場合は、扉の開閉範囲から離れて再操作してください。

## 入口URI・パラメーター
| URI | 内容 |
| --- | --- |
| `/` または `/index.html` | 夕方の街から探索 |
| `/night.html` または `/index.html?view=night` | 夜の街 |
| `/apartment.html` | メイプル・コート4階の住戸内から開始 |
| `/interior.html` | アトラス・タワー25階ラウンジ |
| `/index.html?spot=atlas` | アトラス入口 |
| `/index.html?spot=common` | カフェ入口 |
| `/index.html?spot=museum` | 美術館入口 |
| `/index.html?spot=halcyon` | ホテル入口 |
| `/index.html?spot=verdant` | ヴェルダント入口 |
| `/index.html?spot=maple` | メイプル入口 |
| `/index.html?spot=canal` | カナル入口 |
| `/index.html?spot=aurora` | オーロラ入口 |
| `/index.html?spot=garden` | 中央公園 |
| `/index.html?spot=atlas&floor=24` | アトラス25階 |
| `/index.html?spot=atlas&floor=25` | アトラス屋上 |
| `/index.html?spot=maple&floor=3` | メイプル4階共用廊下 |
| `/index.html?spot=maple&floor=3&room=living` | メイプル4階の住戸内 |
| `/diagnostics.html` | 実ゲームを起動してコンソールに各種検査結果を出力 |

`spot`は英語スポット名の部分一致。`floor`は0始まりで0が1階、建物の階数と同じ値が屋上。範囲外は制限します。`view=night`は他のパラメーターと併用できます。`test=1`を住宅上階のURIに付けると、設備の切り替え検査を実行して状態を元へ戻します。

## ファイル構成
- `index.html`：ゲーム画面、HUD、ダイアログ。
- `css/style.css`：既存の基本UIとレスポンシブスタイル。

- `js/game.js`：都市生成、移動・衝突、地図、フロア移動、各モジュールの統合。

- `js/lighting.js`：街灯・室内灯・ヘッドライト、シャドウ追従。
- `apartment.html` / `interior.html` / `night.html` / `diagnostics.html`：同じ実ゲームへの起動ショートカット。

## データモデル・保存
バックエンド、Table API、サーバーデータベースは使用しません。
- `buildings[]`：建物ID・座標・サイズ・階数・用途・名前・階別の家具衝突・窓・照明・住戸情報。
- `units[floor]`：左右住戸、入口、各部屋への到達検査用座標、寸法、配色。
- `lights[floor]`：実際の器具座標、色、強さ、点灯状態。
- `vehicles[]` / `people[]`：走行軸、方向、レーン、位置、速度、停止理由、描画メッシュ。
- `EvercityTraffic.intersections[]`：64交差点の位置・周期オフセット。
- `EvercityInteractions.states`：建物・階・住戸・設備IDをキーにしたページ内Map。
- `localStorage['evercity-exploration-v1']`：発見済み建物IDのJSON配列。旧版の探索記録を引き継ぎます。
- プレイヤー位置・設定・設備状態は永続保存しません。端末間同期なし。

## 検証結果
- `/diagnostics.html`で実ゲームを起動して検査。
- 都市・入口・壁・上階など11項目：すべてtrue。
- 信号の排他制御、赤停止、青発進、車間、歩行者待機・横断、衝突など12項目：すべてtrue。
- モデル階の左右住戸について、エレベーター前から入口・リビング・キッチン・主寝室・第二寝室・浴室への到達を0.4m格子の幅優先探索で検証。照明数を含む14項目：すべてtrue。経路検査では玄関扉を開いた状態の通路を想定し、扉自体は別に検査。
- 扉の開閉状態と当たり判定、照明・テレビ・水栓の切り替え／復元8項目：すべてtrue。
- 合計45項目の検査で失敗なし。全624住戸を個別に歩行検証したものではありません。
- ブラウザコンソールでアプリケーションのJavaScript例外なし。
- 最新版の夜景（PC）、都市（スマホ）、詳細住戸（PC・スマホ）を実際のスクリーンショットで確認。
- Three.js旧配布形式の非推奨警告と、ヘッドレス検証環境のソフトウェアWebGL警告は発生します。
- 実機スマホの長時間テストは未実施。

## 未実装・制約
- 実在都市、無限生成、写実的モデル、レイトレーシング。
- 階段による全階連続移動、実時間で昇降するエレベーター。
- 運転・乗車、右左折する道路ネットワーク、NPCの会話や生活AI。
- 交通参加者は決められた直線ルートを使う。全市の経路探索ではない。
- マルチプレイヤー、戦闘、ストーリー、買い物、物理破壊。
- 全小物の衝突、家具の移動、すべての収納・家電の操作。
- テレビは手続き型グラフィック。水栓は見た目の水流。実際の放送・水量シミュレーションなし。
- 鏡は装飾的な反射風素材。リアルタイム鏡面反射ではない。
- 全建物・全住戸が完全に独自の間取りではなく、用途別の生成パターンを共有。
- 動く車・歩行者の完全な動的落ち影、世界全体の同時点光源。
