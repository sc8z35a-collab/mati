## 探索と操作

約648m四方、76棟、5公園。南側の入口から建物へ入り、奥のエレベーターで各階・屋上へ移動します。住宅・ホテルの偶数インデックス階には、開閉する扉を備えたバルコニーがあります。

| 操作           | PC                          | タッチ端末                         |
| -------------- | --------------------------- | ---------------------------------- |
| 移動・視点     | WASD / 矢印、マウスドラッグ | 左側を触れて移動、右側をスワイプ   |
| 走る           | Shift                       | ↟                                  |
| 設備・会話     | E                           | 操作名横のボタン                   |
| 地図           | M                           | メニュー → 都市マップ              |
| 依頼           | J                           | 追跡カード / メニュー → 街歩き手帳 |
| カメラ         | P、Enterで撮影              | メニュー → 写真を撮る              |
| 住戸設備ガイド | H                           | メニュー → 住戸の設備              |
| 全画面         | F                           | 右上の⛶                            |

案内カードとミニマップは設定で非表示にできます。扉を閉めるときは開閉範囲から離れてください。ジャンプと着地は高さ付きの当たり判定を使用しますが、剛体物理・転落・ラグドールは実装していません。

## 写真

探索中の画質とは別に、撮影品質・解像度・縦横比を選びます。

- 長辺1920pxまたは3840px。16:9なら4Kは3840×2160、9:16なら2160×3840です。
- 16:9、4:3、1:1、9:16。画面の枠、依頼の構図判定、書き出しで同じ投影計算を使います。
- 軽量品質でも実解像度の4Kタイル描画を実行します。拡大補間による4K化ではありません。
- HDR対応端末では高精細2サンプル、最高品質8サンプル。HDR合成後にACESで**sRGB / SDR PNG**へ変換します。HDRディスプレイ向けファイルではありません。
- 画角25〜95°、露出補正、傾き。依頼撮影では階・距離・フレーム内・遮蔽物・指定された時間帯／天候を判定します。
- 撮影中は街と視点を停止。キャンセル・失敗時は探索画質と描画サイズを復元します。
- アルバムの原寸画像は自動削除しません。利用者が削除した場合だけ取り除きます。
- 一覧は独立した小さなプレビューを24枚ずつ表示し、原寸画像は選択時に読み込みます。旧アルバムのプレビューは表示時に順次作成します。
- 保存容量不足などで永続保存できなければ、その旨を表示して端末へのダウンロードを案内します。ブラウザ内の記録は端末間では同期しません。

## 街でできること

10件の依頼、6人の会話相手。公園・美術館・屋上・入口の撮影、コーヒー豆の配達、昼夜や雨の写真散歩があります。ECでコーヒー、散歩靴、屋上パスを購入できます。コーヒーの残り時間と購入済みの道具も保存します。

住宅は建物ごとに居室の比率を変え、オフィスには執務席・会議テーブル・少人数の作業席を配置しています。すべての住戸が個別設計という意味ではありません。

40台の車と95人の歩行者。共通の信号時計を使い、車の右左折では交差点を予約して譲り合います。一部の歩行者は沿道の建物へ立ち寄ります。市民の職業・家族・経済を再現する生活シミュレーションではありません。

## 表示と音

初回の探索品質はPCでHIGH、タッチ端末でBALANCED。10秒間の大半で描画が重かった場合は一段階下げます。設定で自動調整を無効にできます。描画画素数・遠景ディテール・影に上限を設け、ダイアログ表示中は描画頻度を抑えます。

建物の屋上形状、窓枠の密度、葉・花・材質・配色を調整しています。反射は実際のシーンを低解像度のキューブマップへ記録する近似です。鏡や窓の正確な平面反射・レイトレーシングではありません。影と照明の範囲にも予算があります。

空と太陽光は時間帯の変更時に補間します。室内から屋外の雨は見え、屋根の下の雨粒を除外します。環境音を有効にすると雨・風・近くの車・足音を合成します。最初の有効化には利用者の操作が必要です。

## 保存・復旧

- `evercity-stories-v3`: 位置、階、向き、依頼、EC、購入品、コーヒーの残り時間、時間帯、天候。
- 通常起動では前回の位置を復元してから探索を開始します。明示的な`spot`指定と診断起動はその開始指定を優先します。
- `evercity-exploration-v1`: 発見済みの建物。
- `evercity-quality-v1` / `evercity-controls-v1` / `evercity-hud`: 品質・操作・HUD設定。
- IndexedDB `evercity-photo-album` v2: `photos`に原寸、`previews`にメタデータと縮小画像。v1からの移行あり。
- 住戸設備の状態は現在のページ内で保持します。再読み込みをまたぐ設備状態の永続化は対象外です。
- WebGLの中断時は位置の保存を試み、軽量設定で再読み込みするボタンを表示します。

## 起動・構成

静的ファイルをHTTPサーバーで配信します。Three.jsはjsDelivr、書体はGoogle Fontsから読み込みます。

`night.html` / `apartment.html` / `interior.html` は起動ショートカットです。`?spot=maple&floor=2`の階番号は0始まり。`test=1`は自己診断・状態変更用のフックを有効にする開発用指定です。通常起動では自己診断を実行しません。

| ファイル                                  | 役割                                       |
| ----------------------------------------- | ------------------------------------------ |
| `js/game.js`                              | 都市生成、移動、地図、統合                 |
| `js/traffic.js`                           | 交通時計、右左折、歩行者、近傍検索         |
| `js/residences.js` / `js/interactions.js` | 住戸と設備                                 |
| `js/lighting.js`                          | 照明、HDR後処理、HDRタイル撮影             |
| `js/photography.js`                       | 投影・遮蔽物判定、軽量タイル撮影、縮小画像 |
| `js/stories.js`                           | 依頼、会話、保存、アルバム                 |
| `js/exterior.js` / `js/environment.js`    | 外観、反射、空・天候                       |
| `js/audio.js`                             | 位置と状況に応じた音                       |
